# Security Policy

Luma Linux is currently an alpha project and does not yet provide formal
security support for produced ISO images.

## Reporting

For now, report security issues privately to the repository owner, or open a
GitHub security advisory if the repository has advisories enabled.

## Scope

Security fixes for project scripts, build configuration, and repository
metadata are in scope.

Security updates for Debian packages are handled through Debian security
repositories. Luma images should be rebuilt regularly from current Debian
security package indexes.
