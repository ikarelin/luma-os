# LumaOS Logo Directions

These are early SVG sketches for LumaOS. They are meant to choose a visual
direction before producing a final production logo, icon set, and brand guide.

The shared direction is modern Linux desktop branding: blue-first, simple at
small sizes, rounded geometry, and a little luminous depth without copying any
existing distribution mark.

## Generator Prompts

### Aurora L

Minimal vector logo for an open source Linux desktop OS named LumaOS, rounded
capital L built from two translucent blue aurora light bands, premium but
friendly, deep azure to cyan gradient, simple silhouette, no text, no Apple
style, no Debian swirl, no Fedora infinity, scalable app icon on transparent
background.

### Aurora Monoline

Minimal vector logo for LumaOS, a single rounded monoline capital L drawn like
a blue aurora light trail, deep navy background, cyan highlight, very simple
and readable at small sizes, no text, no existing Linux distro symbols.

### Aurora Glass

Premium glass-style app icon for LumaOS, rounded square blue background, soft
translucent aurora L inside, subtle highlights and depth, modern Linux desktop
identity, no text, no Apple logo, no Debian swirl, no Fedora infinity.

### Aurora Ring

Modern Linux OS emblem for LumaOS, luminous rounded L in the center with a thin
cyan aurora ring around it, trustworthy blue palette, simple vector geometry,
community and desktop platform feeling, no copied distro marks, no text.

### Aurora Core Large

Modern vector logo for LumaOS, enlarged rounded capital L from a blue aurora
light shape, no circle, no orbit, confident central mark, deep navy background,
cyan to royal blue gradient, simple enough for a Linux distribution icon, no
text, no existing distro marks.

### Aurora Core Glow

LumaOS logo concept, large rounded luminous L without any surrounding ring,
soft cyan glow, premium blue desktop OS branding, clean vector icon, deep navy
background, readable at small sizes, no text, no Apple or Debian references.

### Aurora Core Glass

Glass-style LumaOS app icon, large rounded L shape only, translucent blue
facets and white inner highlight, modern Linux desktop distribution branding,
no surrounding circle, no text, no copied logos.

### Aurora Core Cut

Technical but friendly LumaOS logo, large rounded blue L with a diagonal prism
cut and luminous edge, no circle around the mark, precise vector geometry,
deep blue palette, no text, no existing distro symbols.

### Aurora Core Flat

Flat minimal LumaOS logo, large rounded capital L in blue and cyan, no circle,
no glow except tiny highlight, works for favicon, bootloader and package
icons, vector mark only, no text.

### Aurora Fold

Vector brand mark for LumaOS, folded ribbon capital L made from overlapping
blue aurora surfaces, subtle glass gradient, polished desktop OS logo, rounded
corners, transparent or deep navy background, no text.

### Aurora Flat

Flat minimal LumaOS icon, bold rounded capital L in bright blue and cyan, no
gradients except a tiny highlight, designed for bootloader, favicon and package
branding, clean Linux distribution logo, no text.

### Orbit Core

Modern vector logo for LumaOS, luminous blue circular core with one clean
orbital path forming a subtle L shape, community and operating system identity,
flat geometric mark with soft gradient, deep blue and cyan, no text, no
trademarks, simple enough for 16px app icon.

### Prism Drop

Friendly Linux distribution logo for LumaOS, rounded droplet or lens shape with
a faceted prism cut inside, blue glass gradient, minimal geometry, elegant
desktop OS brand, no animal mascot, no Debian swirl, no Fedora shape, no text,
transparent background.

### Ribbon Window

Clean operating system logo for LumaOS, four soft blue folded panes forming a
subtle window and letter L, modern gradient, trustworthy desktop platform,
simple vector icon, rounded corners, transparent background, no Windows logo
copy, no text.

### Wave Leaf

Open source desktop OS logo for LumaOS, abstract blue leaf-wave made of two
rounded strokes, fresh and approachable like Linux Mint but not green and not a
leaf copy, luminous cyan highlight, minimal vector, no text, transparent
background.
